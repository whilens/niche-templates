# Niche Templates

Десять нишевых лендингов (октябрьский ТОП-10): один визуальный шаблон на нишу.

## Ниши

| URL | Ниша |
|-----|------|
| `/shinomontazh` | Шиномонтаж |
| `/logoped` | Логопеды |
| `/nedvizhimost` | Управление недвижимостью |
| `/psihologiya` | Психология |
| `/potolki` | Натяжные потолки |
| `/kvesty` | Квесты |
| `/diagnostika` | Диагностический центр |
| `/urologiya` | Урология |
| `/stomatologiya` | Стоматология |
| `/ginekologiya` | Гинекология |

## Локально

```bash
npm install
npm run dev
```

Откройте http://127.0.0.1:4321
